# Flight Booking System

## Project Description

The Flight Booking System is a C-based application designed to
simulate basic flight booking operations.

## Features

- Admin authentication
- Add flight
- Delete/cancel flight
- View flights
- Search flights
- Sort flights
- Booking
- Booking cancellation
- Report generation
- File handling

## Technologies Used

- C Programming
- Structures
- Pointers
- Functions
- Strings
- Searching
- Sorting
- File Handling
